## Default Permission

Allows all content-update commands: reading the state, confirming the running bundle, checking for, downloading, applying and resetting bundles.

#### This default permission set includes the following:

- `allow-get-state`
- `allow-notify-ready`
- `allow-check`
- `allow-download`
- `allow-apply`
- `allow-reset`
